MAME is the definitive multi-system emulator preserving over 40,000 arcade, console, and computer hardware configurations for educational and historical purposes.

Whether you're a newcomer or a veteran, MAME provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
